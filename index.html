System Modules

This system supports the following modules:

  • Register new food donations from restaurants, cafes, bakeries, supermarkets, and individuals.
  • Display and track all registered donations in a structured table.
  • Search, update, and delete donations using donor credentials.
  • Assign food items to distribution centers and delivery drivers.
  • Mark assigned food items as delivered.
  • View urgent food donations that require priority delivery.
  • Generate summary reports covering total, available, assigned, delivered, and urgent food.

Note: Actual data processing and system functionality will be implemented in the Java stage.
